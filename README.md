## How agents deliver a paid client (5–7 days)

Assume payment cleared and brief received. Clock starts when **brief + access** land (Shopify collaborator **or** Pages interim choice + product/supplier inputs).

### Day 0 — Intake lock (same day as brief)

1. Confirm tier: **$297** (1 PDP) vs **$497** (2 PDPs + fulfill CSV + SOP).
2. Collect: brand/voice, 1–2 SKUs or supplier links, customer one-liner, logo/colors (optional), Shopify vs GitHub Pages, customer checkout approach (**client’s** method — we do not invent connectors).
3. Confirm ship reality: overseas dropship → default storefront ETA **15–30 days · tracked**; if domestic/faster, use **supplier-confirmed** window only.
4. Copy this kit into the client working folder; replace placeholders (`{{BRAND}}`, `{{SKU}}`, etc.). **Never** leave Nestora product names in client assets.

### Days 1–2 — Store shell + policies

1. Stand up Shopify trial/store **or** GitHub Pages interim LP (per brief).
2. Paste [policy-stubs.md](./policy-stubs.md) into Shipping / Returns / Privacy pages; swap brand name; keep honesty lines.
3. Wire nav + footer links; soft About if needed (no fake claims).
4. Seed [utm-sheet.md](./utm-sheet.md) with client brand slug.

### Days 2–4 — PDP(s)

1. Fill [pdp-template.md](./pdp-template.md) per SKU (title, bullets, under-price ship line, FAQ stubs, claims hard-no).
2. Publish to Shopify product(s) **or** Pages product section. Under-price line must say honest ETA (default: `Typically ships in 15–30 days · tracked from overseas`).
3. Map supplier URL + SKU codes into notes (Launch pack: also fill fulfill sheet columns).
4. One internal QA pass: no trademark misuse, no medical/FDA fantasy, no “Prime speed,” no free-shipping claim unless ops-confirmed.

### Days 4–5 — Fulfill path (required for $497; optional stub for $297)

1. Customize [fulfill-sop.md](./fulfill-sop.md) with hero + backup supplier links and retail.
2. Initialize [fulfill-template.csv](./fulfill-template.csv) (header + example blank row only).
3. Walk founder through “payment clears → place AE order → paste tracking → log row.”

### Days 5–6 — Soft QA + revision window start

1. Client review of live v1 URLs.
2. **One structured revision round** on PDP copy + layout notes (within 5 days of v1 — per FAQ).
3. Confirm UTM example links work on bio/CTA.

### Day 7 — Handoff

1. Complete [handoff-doc.md](./handoff-doc.md) checklist with client.
2. Deliver: live URL(s), filled templates, policy pages, UTM sheet, fulfill SOP/CSV (if Launch pack).
3. Offer optional **$97/mo** light ops (nudges / minor tweaks — not ads, not full VA).
4. Archive working folder; do not reuse client branded assets for other clients.
